Deploy YOLO v8 and train datasets on Windows PC

This document records how to set up a YOLO v8 inference system and train the datasets on a Windows PC

Part A. Environment set up and architecture design

Following dependecies are required for running YOLO v8: You are required to follow a sequence to conduct installation.

1. Conda environment config

There are Miniconda and Anaconda two types of software. The difference between them is that the former one will only install the basic Python packages after initialisation, but the latter one will give you all handy packages and GUI called Navigator after initialisation. I'll use Miniconda for demonstration.

1.1 Installation

You can download from official website and choose the right version (Windows x64) of installation wizard, just follow the steps it prompted. Make sure you have adequate disk volume and install it at default location, this action could prevent unnecessary troubles.

1.2 Create virtual environment and start using

After installation, you can find Anaconda Prompt and Anaconda Powershell Prompt, it indicates that conda environment is successfully installed.
Start one of them, it indicates that you are running conda if the `(base)` is shown. 


        conda create -n yolov8 python=3.8
